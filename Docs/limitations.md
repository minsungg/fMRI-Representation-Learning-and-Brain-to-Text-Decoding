# 실험의 한계

현재 결과의 해석 범위와 구현상 확인 사항을 정리했다. 실험 과정과 생성 예시는 [실험 기록](experiment_log.md)을 참고한다.

## 전처리와 입력 표현

### 생략한 공간 정합

메모리 제약으로 기능영상과 구조영상의 coregistration, 표준공간 normalization을 생략했다. MNI152 마스크를 영상 격자에 resampling했지만, 이는 해부학적 정합을 대신하지 않는다.

움직임 보정과 motion parameter·FD 계산은 수행했다. 다만 해당 값을 GLM confound로 전달하거나 움직임이 큰 frame을 제외하지는 않았다.

### 제공 data와 직접 전처리한 data의 차이

주 학습에는 제공된 betamap을 사용했고, 직접 추출한 betamap은 별도 입력으로 테스트했다. 두 data는 마스크, 공간 정합, voxel 순서, GLM 설정 및 값의 분포가 다를 수 있다.

`AdaptiveAvgPool1d(100000)`은 벡터 길이를 맞추지만 해부학적 위치를 대응시키지는 않는다. 직접 전처리한 입력에서 나타난 예측 집중·캡션 반복을 특정 생략 단계 하나의 영향으로 분리해 확인하지는 않았다.

또한 1D CNN은 평탄화한 벡터를 처리한다. 벡터상의 이웃이 뇌의 3D 공간 이웃을 완전히 보존하는 것은 아니다.

## 데이터 분할과 모델 선택

- **HCP:** sample 단위 무작위 분할이다. 따라서 Macro-F1 0.8667은 해당 분할의 결과이며, 새로운 피험자에 대한 일반화 성능을 뜻하지 않는다.
- **NSD:** sample 단위 `random_split`을 사용했다. 동일 이미지의 반복 측정을 묶지 않아 train/test 간 이미지 중복 가능성이 있다. 실제 중복 수는 집계하지 않았다.
- **최종 모델:** HCP는 validation 최적 checkpoint가 아니라 마지막 epoch의 가중치를 저장했다. 학습 후반에는 train loss와 validation loss의 차이가 커졌다.
- **설정 비교:** feature dimension, prefix 수, encoder 구조 등을 변경했지만, 각 요소의 기여도를 분리한 비교표는 없다. HCP pretrained encoder와 random initialization의 정량 비교도 수행하지 않았다.

## 캡션 평가

노트북에는 BLEU·METEOR·ROUGE-L 출력이 남아 있다. 다만 현재 저장된 코드의 reference 구성은 확인이 필요하다.

`NSDCaptionDataset`은 이미지별 캡션 하나를 선택해 반환한다. 평가에서는 `refs_text = target_captions[i]`를 다시 순회한다. 이 값이 문자열이면 캡션 목록이 아니라 문자를 순회하게 된다. 직접 전처리한 입력의 평가에도 같은 순회 구조가 있다.

실제 실행 batch의 자료형을 확인하고 reference를 올바르게 구성한 뒤 재평가하기 전까지, 이 문서에서는 저장된 수치를 대표 성능으로 사용하지 않는다. 생성 문장 자체는 정성적 결과로 제시했다.

그 밖의 평가 범위는 다음과 같다.

- 이미지마다 선택한 캡션 하나를 사용하며, 전체 COCO reference를 함께 평가하지 않는다.
- CIDEr는 계산하지 않았다.
- 생성 샘플의 `Batch / Item` 표시는 실제 COCO 이미지 ID가 아니다.

## 학습 loss와 생성 결과

학습 시 정답 캡션을 입력하는 teacher forcing과, 추론 시 brain-prefix만으로 문장을 생성하는 조건은 다르다. 따라서 loss 감소만으로 자극 내용을 정확히 반영한다고 판단할 수는 없다.

현재 구현은 prefix 위치를 loss에서 제외하지만 캡션의 padding 위치는 별도로 제외하지 않는다. padding token으로 EOS를 사용하므로, 기록된 loss에는 padding 위치의 예측도 포함된다.

GPT-2가 문장을 생성할 수 있다는 것과 뇌 신호가 그 내용을 결정한다는 것도 구분해야 한다. 일부 실제 입력에서 개념 중첩이 관찰됐지만 다른 대상을 생성하는 경우가 많았고, zero·random 입력에서도 문장이 나왔다. 현재 입력 통제 테스트는 간단한 정성 비교이며 shuffled-input 등의 정량 비교는 수행하지 않았다.

## 실행과 재현

노트북은 당시 Colab 및 로컬 data 경로에 의존한다. 02는 01의 전처리 함수, 04는 03의 encoder 정의와 저장 가중치가 필요하다. NSD의 캡션 선택과 분할 seed도 해당 파일에서 고정하지 않았다.

문서에 제시한 결과는 저장된 실행 기록이며, 문서 작성 과정에서 재학습하거나 재평가한 값은 아니다.
